# 🪨📄✂️ Mini Projetos – Pedra, Papel e Tesoura

## 📌 Descrição

Este repositório contém um **mini projeto do jogo Pedra, Papel e Tesoura**, desenvolvido em **Python**, com o objetivo de **aplicar e consolidar conceitos fundamentais da linguagem** por meio de um mini game interativo no terminal.

O projeto foi pensado como uma forma prática de aprendizado, unindo lógica de programação com uma aplicação simples e divertida.

---

## 🎯 Objetivo do Projeto

* Praticar conceitos básicos e intermediários de Python
* Desenvolver raciocínio lógico
* Criar um jogo interativo no terminal
* Entender o fluxo de decisão com estruturas condicionais

---

## 🧠 Conceitos Aplicados

* Entrada e saída de dados (`input` e `print`)
* Estruturas condicionais (`if`, `elif`, `else`)
* Estruturas de repetição (`while` ou `for`)
* Geração de valores aleatórios (`random`)
* Funções
* Comparação de resultados
* Organização básica do código

---

## 🎮 Como Funciona o Jogo

* O jogador escolhe entre **Pedra**, **Papel** ou **Tesoura**
* O computador faz uma escolha aleatória
* O programa compara as escolhas
* O vencedor é exibido na tela
